1 概述

现当代文学理论研究是汉语言文学专业的重要组成部分，涵盖了中国现代文学史、当代文学史、现代文学理论、文学批评史等多个领域。本书目精选了35部现当代文学理论研究的经典著作，既包括现代文学发展史的重要研究，也涵盖了当代文学理论的前沿成果。

这些著作不仅展现了中国现当代文学的发展历程和理论建构，也体现了学者们对文学现象的深入思考和理论创新。通过系统学习这些经典著作，可以全面了解中国现当代文学的发展脉络、理论特色和时代精神。

2 核心必读书目

2.1 现代文学史研究

  1. 《中国新文学整体观》 - 陈思和，上海文艺出版社1987

    • 现代文学整体性研究的重要著作

  2. 《中国现代文学批评史》 - 温儒敏，北京大学出版社1993

    • 现代文学批评发展史的权威研究

  3. 《中国现代小说流派史》 - 严家炎，人民文学出版社1989

    • 现代小说流派发展的系统研究

  4. 《中国现代小说史》 - 夏志清，上海复旦大学出版社2005

    • 海外学者的现代小说史研究经典

  5. 《中国现代小说叙事模式的转变》 - 陈平原，北京大学出版社1988

    • 现代小说叙事理论的重要研究

2.2 现代文学理论与思想

  1. 《二十世纪中国小说理论资料》 - 严家炎、洪子诚等编，北京大学出版社

    • 现代小说理论的重要史料汇编

  2. 《中国现代思想史论》 - 李泽厚，三联书店出版社2008

    • 现代思想发展的哲学思考

  3. 《中国现代戏剧史稿1899-1949》 - 陈白尘、董健，中国戏剧出版社2008

    • 现代戏剧发展史的权威著作

  4. 《中国新诗流变论》 - 龙泉明，人民文学出版社2003

    • 现代诗歌发展的理论研究

  5. 《中国现代散文史稿》 - 林非，中国社会科学出版社1981

    • 现代散文发展史的系统研究

2.3 当代文学研究

  1. 《中国当代新诗史》 - 洪子诚、刘登翰，北京大学出版社2005

    • 当代诗歌发展史的重要研究

  2. 《当代文学关键词》 - 洪子诚、孟繁华主编，广西师大出版社2002

    • 当代文学理论的关键概念解析

  3. 《想象中国的方法历史、小说、叙事》 - 王德威，北京三联书店2003

    • 当代文学研究的理论创新

  4. 《中国当代文学史料选》 - 谢冕、洪子诚，北京大学出版社1995

    • 当代文学发展的重要史料

  5. 《中国当代文学思潮史》 - 朱寨，人民文学出版社1987

    • 当代文学思潮发展的系统研究

2.4 文学理论与批评

  1. 《中国的文学理论》 - [美]刘若愚，四川人民出版社1987

    • 海外学者对中国文学理论的研究

  2. 《文学心理学》 - 钱谷融、鲁枢元主编，华东师范大学出版社2003

    • 文学心理学理论的重要著作

  3. 《文化研究读本》 - 罗钢、刘象愚主编，中国社会科学出版社2000

    • 文化研究理论的重要文献

  4. 《叙述学研究》 - 张寅德编选，中国社会科学出版社1989

    • 叙述学理论的重要选编

  5. 《中国文论英译与评论》 - [美]宇文所安，上海社会科学院出版社2003

    • 中国文论的跨文化研究

2.5 文艺理论与美学

  1. 《文艺心理学》 - 朱光潜，复旦大学出版社2005

    • 文艺心理学的经典著作

  2. 《中国文学批评通史》 - 王运熙、顾易生主编，上海古籍出版社1996

    • 中国文学批评史的通史性著作

  3. 《被开拓的诗世界》 - 程千帆、莫砺锋、张宏生著，上海古籍出版社1990

    • 诗歌研究的重要成果

  4. 《中国新文学大系1949-1976》 - 冯牧、王蒙、吴祖光等编，上海文艺出版社1997

    • 当代文学发展的重要文献

  5. 《管锥编》 - 钱钟书著，三联书店2008

    • 文学研究的博学之作

2.6 文学理论教程

  1. 《文学理论学导论》 - 董学文著，北京大学出版社2004

    • 文学理论学的系统教程

  2. 《中国文艺理论百年教程》 - 毛庆耆等著，广东高等教育出版社2004

    • 中国文艺理论发展的百年回顾

  3. 《叙事学与小说文体学研究》 - 申丹著，北京大学出版社1998

    • 叙事学理论的专门研究

2.7 现代文学史料与文献

  1. 《中国新文学大系：导言集》 - 鲁迅等著，天津人民出版社2009

    • 现代文学发展的重要史料

  2. 《五十年之中国文学》 - 胡适，《胡适文集》，北京大学出版社1998

    • 现代文学发展的亲历者回顾

  3. 《中国新文学的源流》 - 周作人，江苏文艺出版社2007

    • 现代文学起源的重要论述

2.8 文学研究现代化

  1. 《中国现代文学论集》 - 王瑶，北京大学出版社1998

    • 现代文学研究的经典论文集

  2. 《西方影响与民族风格》 - 唐强，人民文学出版社1989

    • 现代文学中西文化交流的研究

  3. 《中国文学研究现代化进程》 - 王瑶主编，北京大学出版社1996

    • 文学研究方法现代化的探讨

  4. 《中国文学研究现代化进程二编》 - 陈平原主编，北京大学出版社2002

    • 文学研究现代化的进一步探索

3 阅读指南

3.1 学习层次划分

基础阶段（本科1-2年级）

  • 重点阅读：《中国新文学整体观》、《中国现代文学批评史》
  • 建立现当代文学的基本知识框架

提高阶段（本科3-4年级）

  • 重点阅读：《中国现代小说史》、《当代文学关键词》
  • 深入理解现当代文学的发展脉络

研究阶段（研究生）

  • 重点阅读：各种理论专著和前沿研究成果
  • 掌握现当代文学研究的理论和方法

3.2 阅读方法建议

  1. 史论结合：将文学史与文学理论相结合
  2. 中外对比：关注中外学者的不同研究视角
  3. 理论实践并重：理论学习与文本分析相结合
  4. 时代背景考察：在特定历史语境中理解文学现象

3.3 重点关注内容

  1. 文学发展脉络：现当代文学的历史发展轨迹
  2. 理论建构过程：现当代文学理论的形成和发展
  3. 文化思想背景：文学与时代思想文化的关系
  4. 研究方法创新：现当代文学研究方法的演进

3.4 学习要点

  1. 掌握核心概念：现代性、民族性、世界性等核心概念
  2. 理解理论体系：各种文学理论的内在逻辑和特点
  3. 培养批评能力：运用理论分析现当代文学作品
  4. 关注学术前沿：了解现当代文学研究的最新动态

3.5 研究视角建议

  1. 历史视角：在历史发展中把握文学现象
  2. 比较视角：中外文学的比较研究
  3. 跨学科视角：文学与其他学科的交叉研究
  4. 文化视角：文学与文化的互动关系

3.6 版本选择建议

  1. 最新修订版：选择最新修订的版本
  2. 权威出版社：优选知名大学出版社和专业出版社
  3. 学术声誉：选择学术声誉良好的学者著作
  4. 资料完备：选择资料丰富、注释详细的版本

注：本书目根据汉语言文学专业教学需要整理，建议结合具体课程安排和个人研究兴趣进行选择性阅读。
