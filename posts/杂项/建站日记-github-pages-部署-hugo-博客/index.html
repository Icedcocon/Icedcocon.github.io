1 Hugo 配置

1.1 容器化配置 Hugo 测试环境

1.1.1 启动镜像并初始化博客

hugo 镜像名称的含义可以根据文档确定

docker pull hugomods/hugo:debian-reg-node-git-0.147.7
docker run -it --rm --name hugo -v /mnt/nanopc/Repo:/src hugomods/hugo:debian-reg-node-git-0.147.7 bash
# 使用 --force 可以在已存在的仓库中初始化; --format yaml 使用 yaml 格式配置文件
hugo new site blogs  --force --format yaml
Tip

仅初始化需要在仓库的上级路径执行指令，所以在后续调整 Hugo 配置及内容时，可以使用以下指令直接启动开发服务器 docker run -itd --network host --rm --name hugo -v /mnt/nanopc/Repo/HugoBlogs:/src hugomods/hugo:debian-reg-node-git-0.147.7 hugo serve --bind 0.0.0.0 --baseURL http://192.168.2.20

1.1.2 安装主题

推荐使用 PaperMod 主题。

cd blogs
git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
git submodule update --init --recursive # needed when you reclone your repo (submodules may not get cloned automatically)

1.1.3 启动服务

执行以下指令，在服务启动后，访问 http://192.168.2.20:1313 即可查看博客。

hugo serve --bind 0.0.0.0  --baseURL http://192.168.2.20

2 GitHub 配置

2.1 创建仓库

2.1.1 创建 blog 仓库

用于存储博客源文件，也就是刚才的本地项目文件。

2.1.2 创建 Github Pages 公开仓库

用于实际展示博客。

Warning

Repository name 这里一定要填 [你的github账号].github.io。你的github账号必须小写字母。仓库可见性设为Public。选择“使用 README 初始化此存储库”。

2.2 配置 Deploy keys

2.2.1 生成一对密钥

创建一个新路径或者进入~/.ssh，以下指令会生成一对密钥文件，请存放在适当位置。

ssh-keygen -t rsa -b 4096 -C "$(git config user.email)" -f icedcocon-pages -N ""

上述指令会生成公钥 icedcocon-pages.pub 和私钥 icedcocon-pages 。

2.3 配置 Deploy keys

将私钥填入私有仓库 Icedcocon/blogs 的 Settings - Secrets - Actions ，单击 New reposity secret。

Tip

可以直接访问地址: https://github.com/<account>/<reposity>/settings/secrets/actions

将公钥填入公共仓库 Icedcocon/Icedcocon.github.io 的 Settings - Deploy keys ， 单击 Add deploy keys 。

Tip

可以直接访问地址: https://github.com/<account>/<reposity>/settings/keys

2.4 配置自定义域名

2.4.1 域名解析配置

在DNS管理平台如 cloudflare 完成以下配置

CNAME   www.you-domain    icedcocon.github.io
A       you-domain        185.199.108.153
A       you-domain        185.199.109.153
A       you-domain        185.199.110.153
A       you-domain        185.199.111.153

2.4.2 在 Github Pages 配置自定义域名

访问自定义域名配置页面， 如 https://github.com/<account>/<reposity>/settings/pages 。在 Custom domain 处填写域名，如www.65811786.xyz ，单击保存并勾选 Enforce HTTPS 选项。

2.4.3 在项目 static 路径创建 CNAME 文件

CNAME文件是GitHub Pages用来识别您的自定义域名的关键文件。 static/CNAME 中的内容如下：

www.65811786.xyz
Warning

当不存在此文件时，每次自动部署时，自定义域名(Custom domain)被取消并恢复 GitHub 域名。

3.1 虚拟环境准备

本小节用于说明在 incus 容器中配置 docker 方便后续容器化部署 Hugo 环境。

3.1.1 启动incus容器并进入（后续均在incus中操作）

incus image list images:debian
incus launch images:debian/12 debain -c security.privileged=true -c security.nesting=true
incus exec debain bash

3.1.2 安装基本依赖

apt update
apt install netplan.io curl

3.1.3 配置网络

cat > /etc/netplan/01-netcfg.yaml <<-EOF
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: false
      addresses: [192.168.2.20/24]
      routes:
        - to: default
          via: 192.168.2.10
          metric: 100
      nameservers:
        addresses: [1.1.1.1, 8.8.8.8]
EOF
chmod 600 /etc/netplan/01-netcfg.yaml
netplan try

3.1.4 安装 docker

curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh --mirror Aliyun
