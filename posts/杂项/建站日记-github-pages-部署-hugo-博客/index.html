1. 容器化配置 Hugo 测试环境#

1.1 启动镜像并初始化博客#

hugo 镜像名称的含义可以根据文档确定

1
2
3
4

docker pull hugomods/hugo:debian-reg-node-git-0.147.7
docker run -it --rm --name hugo -v /mnt/nanopc/Repo:/src hugomods/hugo:debian-reg-node-git-0.147.7 bash
# 使用 --force 可以在已存在的仓库中初始化; --format yaml 使用 yaml 格式配置文件
hugo new site blogs  --force --format yaml

[!TIP] 仅初始化需要在仓库的上级路径执行指令，所以在后续调整 Hugo 配置及内容时，可以使用以下指令直接启动开发服务器 docker run -itd --network host --rm --name hugo -v /mnt/nanopc/Repo/HugoBlogs:/src hugomods/hugo:debian-reg-node-git-0.147.7 hugo serve --bind 0.0.0.0 --baseURL http://192.168.2.20

## 这是一个二级标题

这里是一些示例内容，用于测试文章的显示效果。

二、GitHub 配置#

1. 创建仓库#

1.1 创建 blog 仓库#

用于存储博客源文件，也就是刚才的本地项目文件。

1.2 创建 Github Pages 公开仓库#

用于实际展示博客。

[!WARNING] Repository name 这里一定要填 [你的github账号].github.io。你的github账号必须小写字母。仓库可见性设为Public。选择“使用 README 初始化此存储库”。

2. 配置 Deploy keys#

2.1 生成一对密钥#

创建一个新路径或者进入~/.ssh，以下指令会生成一对密钥文件，请存放在适当位置。

1

ssh-keygen -t rsa -b 4096 -C "$(git config user.email)" -f icedcocon-pages -N ""

上述指令会生成公钥 icedcocon-pages.pub 和私钥 icedcocon-pages 。

2.2 配置 Deploy keys#

将私钥填入私有仓库 Icedcocon/blogs 的 Settings - Secrets - Actions ，单击 New reposity secret。

[!TIP] 可以直接访问地址: https://github.com/<account>/<reposity>/settings/secrets/actions

将公钥填入公共仓库 Icedcocon/Icedcocon.github.io 的 Settings - Deploy keys ， 单击 Add deploy keys 。

[!TIP] 可以直接访问地址: https://github.com/<account>/<reposity>/settings/keys

3. 配置自定义域名#

3.1 域名解析配置#

在DNS管理平台如 cloudflare 完成以下配置

3.2 在 Github Pages 配置自定义域名#

访问自定义域名配置页面， 如 https://github.com/<account>/<reposity>/settings/pages 。在 Custom domain 处填写域名，如www.65811786.xyz ，单击保存并勾选 Enforce HTTPS 选项。

3.3 在项目 static 路径创建 CNAME 文件#

CNAME文件是GitHub Pages用来识别您的自定义域名的关键文件。 static/CNAME 中的内容如下：

1

www.65811786.xyz

[!WARNING] 当不存在此文件时，每次自动部署时，自定义域名(Custom domain)被取消并恢复 GitHub 域名。
